# Página inicial do ServPilot

Site institucional em HTML, CSS e JavaScript puros (sem Flutter), publicado no
Firebase Hosting do projeto `servia-ccdda`, site `servpilot-site`:

    https://servpilot.com.br  (e www.servpilot.com.br, que redireciona)

Quem publica é a esteira (`.\atualizar`, etapa "Página inicial"), só quando algo
aqui muda.

- `public/index.html`: o conteúdo. As telas do app e do painel são desenhadas em
  HTML e CSS, com dados fictícios (nada de dados de clientes).
- `public/estilo.css`: o visual, com as cores da identidade.
- `public/site.js`: o número do WhatsApp comercial (`WHATSAPP`, só números, com
  55 e DDD) e a mensagem que já vem escrita. Vazio, os botões levam para a seção
  de contato.
- `public/img/`: logos e símbolo (da pasta imagens\ServPilot-vetores) e a imagem
  de compartilhamento (`compartilhar.png`, 1200 x 630).
