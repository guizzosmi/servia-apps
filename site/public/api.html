API do ServPilot (OData v4)

Última atualização: 04/11/2026

Integre o ServPilot ao seu ERP (Protheus, por exemplo), ao BI ou a outro sistema. A API segue o padrão OData v4 e expõe os cadastros e movimentos com consulta, inclusão, alteração e exclusão. O administrador da plataforma decide o que fica liberado em cada entidade; o modelo completo, com o que cada uma permite, está no $metadata.

1. Credencial

No painel, em Administração › Integrações (API), o administrador da empresa cria uma credencial para cada sistema. Ela tem um client_id e um client_secret, que aparece uma única vez. A API age como o usuário que criou a credencial, só com os papéis escolhidos nela (gestor, financeiro ou técnico), e sempre dentro das empresas liberadas. Uma credencial pode ser só de consulta. Revogar vale na hora.

2. Autenticação: bearer token e refresh token

POST /api/token
Content-Type: application/x-www-form-urlencoded

grant_type=client_credentials&client_id=SEU_CLIENT_ID&client_secret=SEU_CLIENT_SECRET

Também aceita o client_id e o client_secret no cabeçalho Authorization: Basic. A resposta:

{ "access_token": "eyJ…", "token_type": "Bearer", "expires_in": 900,
  "refresh_token": "spr_…", "refresh_token_expires_in": 2592000 }
  • access_token: vale 15 minutos. Envie em toda chamada: Authorization: Bearer eyJ….
  • refresh_token: vale 30 dias e uma vez só. Troque por um par novo com grant_type=refresh_token&refresh_token=spr_… e guarde o novo. Se um refresh token já usado aparecer de novo, a sessão inteira é encerrada por segurança e é preciso pedir outro token com o client_secret.
  • Limite: 120 chamadas por minuto por credencial (resposta 429 com Retry-After).

3. Empresa e filial: TenantId

A conta é o grupo de empresas; cada empresa (CNPJ) pode ser matriz ou filial. Cadastre no painel os códigos da empresa no ERP (Protheus: grupo, empresa, unidade e filial). Em cada chamada, escolha a filial como no REST do Protheus:

TenantId: 01,0101

Também vale ServPilot-Empresa: <código curto ou id da empresa>. Sem cabeçalho, vale a empresa principal da credencial. A filial precisa estar liberada na credencial.

4. Consultas

GET /api/odata/Clientes?$filter=contains(tolower(nome),'mercado') and ativo eq true
    &$select=nome,documento&$orderby=nome&$top=50&$count=true
GET /api/odata/Clientes(5d1c…)?$expand=Locais($select=nome,cidade)
GET /api/odata/OrdensServico?$filter=status eq 'aberta' and prevista_para le 2026-11-30&$expand=cliente($select=nome)
GET /api/odata/Clientes/$count
OpçãoComo funciona
$filtereq ne gt ge lt le, and or not, in (…), null, contains startswith endswith tolower toupper trim length year month day hour minute date now. Textos entre aspas simples; datas como 2026-11-01 ou 2026-11-01T10:00:00Z; ids sem aspas.
$select, $orderbyCampos separados por vírgula; desc para ordem decrescente.
$expandUm nível, com $select, $filter, $orderby e $top dentro dos parênteses, separados por ;.
$top, $skip, $countSem $top, vêm 100 por página com @odata.nextLink para a próxima. Máximo 1.000 por chamada. Prefer: odata.maxpagesize=N também vale.
incluir_excluidos=trueTraz também os registros excluídos (para sincronizar exclusões).

5. Incluir, alterar e excluir

POST   /api/odata/Clientes            { "tipo": "pj", "nome": "Mercado Bom Preço", "documento": "11111111000111" }
PATCH  /api/odata/Clientes(5d1c…)     { "telefone": "45999990001" }      If-Match: W/"3"   (opcional)
PUT    /api/odata/Clientes(5d1c…)     registro completo (o que não vier volta ao padrão)
DELETE /api/odata/Clientes(5d1c…)
  • Incluir responde 201 com o registro e o cabeçalho Location. Alterar e excluir respondem 204; use Prefer: return=representation para receber o registro alterado.
  • Cada registro traz @odata.etag. Mandando o mesmo valor em If-Match, a alteração só acontece se ninguém mexeu no registro desde a leitura (senão, 412).
  • Excluir é lógico quando a tabela tem exclusão lógica: o registro some das consultas, mas continua no histórico.
  • Campos do sistema (conta_id, empresa_id, versao, datas de criação e alteração) são ignorados na gravação.

6. Movimentos e ações

Ordens de serviço, orçamentos, planos de preventiva e contratos gravam pelas mesmas regras do painel. Incluir uma OS abre a OS com o agendamento; excluir cancela (informe o motivo):

POST   /api/odata/OrdensServico   { "cliente_id": "…", "local_id": "…", "problema_relatado": "Não gela",
                                    "equipamentos": ["…"], "agendamento": { "data_prevista": "2026-11-10" } }
DELETE /api/odata/OrdensServico(…)?motivo=Cliente%20desistiu
POST   /api/odata/OrdensServico(…)/ServPilot.Acao   { "acao": "concluir" }
POST   /api/odata/Orcamentos(…)/ServPilot.Acao      { "acao": "aprovar" }

Itens de OS, atendimentos, medições e similares são só consulta: mudam pela entidade principal.

7. De-para com o ERP: VinculosExternos

Guarde a chave do ERP de cada registro, sem precisar guardar os ids do ServPilot no ERP:

POST /api/odata/VinculosExternos
{ "sistema": "protheus", "entidade": "Clientes", "registro_id": "5d1c…",
  "chave_externa": "000123|01", "filial_externa": "" }

GET /api/odata/VinculosExternos?$filter=entidade eq 'Clientes' and chave_externa eq '000123|01'

filial_externa vazia = cadastro compartilhado no ERP (xFilial em branco).

8. Exemplo em TLPP (Protheus)

#include "tlpp-core.th"

User Function SPClientes() as Logical
  Local oRest   := FWRest():New("https://srtokvosnwtyewiempyw.supabase.co/functions/v1/api")
  Local aHeader := {"Content-Type: application/x-www-form-urlencoded"}
  Local jToken  := JsonObject():New()
  Local cToken  as Character

  oRest:SetPath("/token")
  oRest:SetPostParams("grant_type=client_credentials&client_id=" + SuperGetMV("MV_XSPCID", .F., "") + ;
                      "&client_secret=" + SuperGetMV("MV_XSPSEC", .F., ""))
  If !oRest:Post(aHeader)
    ConOut("ServPilot token: " + oRest:GetLastError())
    Return .F.
  EndIf
  jToken:FromJson(oRest:GetResult())
  cToken := jToken["access_token"]

  oRest:SetPath("/odata/Clientes?$select=nome,documento&$top=100")
  If oRest:Get({"Authorization: Bearer " + cToken, "TenantId: " + cEmpAnt + "," + cFilAnt})
    ConOut(oRest:GetResult())
  EndIf
Return .T.

10. Segurança

  • Só HTTPS. Guarde o client_secret num cofre ou parâmetro protegido; nunca em código-fonte.
  • Uma credencial por sistema, com os menores papéis possíveis. Revogue as que não usa.
  • Cada chamada fica registrada (90 dias) e pode ser vista no painel, na credencial.
